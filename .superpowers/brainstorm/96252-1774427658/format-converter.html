⚠️ 转换提示
SRT 不支持 ASS 样式，样式信息将丢失。文本中的 ASS 标签将被清除。

转换规则

ASS → SRT

  • 时间格式转换 (h:mm:ss.cc → h:mm:ss,mmm)
  • 移除所有样式定义
  • 清除文本中的 ASS 标签
  • 保留纯文本和换行符
  • 显示警告提示样式丢失

SRT → ASS

  • 时间格式转换 (h:mm:ss,mmm → h:mm:ss.cc)
  • 自动创建 Default 样式
  • 保留纯文本和换行符
  • 生成标准 ASS 文件头
  • 用户可后续编辑样式
