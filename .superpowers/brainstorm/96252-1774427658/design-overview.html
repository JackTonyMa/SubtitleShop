技术栈

  • 框架：Vue 3 + TypeScript + Vite
  • 状态管理：Pinia
  • UI 组件：自定义组件 + Tailwind CSS
  • 时间轴：自定义 Canvas/SVG 实现
  • 存储：IndexedDB (localForage)

核心模块

1. Parser Plugin

ASS/SRT 格式解析与序列化，支持插件扩展其他格式

2. Editor Core

字幕数据模型、操作历史(撤销/重做)、选区管理

3. Style Engine

ASS 完整样式支持：字体、颜色、边框、阴影、旋转、渐变等

4. Timeline Editor

可视化时间轴，拖拽调整时间、缩放、滚动、多轨道

5. Table Editor

传统列表视图，直接编辑时间码和文本

6. Format Converter

ASS ↔ SRT 双向转换，处理样式丢失警告
