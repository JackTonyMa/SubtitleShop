模块划分

src/
├── core/                    # 核心引擎
│   ├── models/              # 数据模型 (SubtitleItem, AssStyle, etc.)
│   ├── history/             # 操作历史管理
│   └── plugins/             # 插件系统
├── plugins/                 # 官方插件
│   ├── parser-ass/          # ASS 解析器插件
│   ├── parser-srt/          # SRT 解析器插件
│   ├── exporter/            # 导出插件
│   └── converter/           # 格式转换插件
├── components/              # Vue 组件
│   ├── timeline/            # 时间轴组件
│   ├── table/               # 表格编辑组件
│   ├── style-editor/        # 样式编辑器组件
│   └── common/              # 通用组件
├── stores/                  # Pinia 状态管理
├── composables/             # Vue 组合式函数
├── utils/                   # 工具函数
└── App.vue                  # 应用入口

开发阶段（建议）

  1. Phase 1 - 基础框架：项目搭建、插件系统、数据模型、ASS/SRT 解析器
  2. Phase 2 - 核心编辑：表格视图、时间轴编辑器、基础操作
  3. Phase 3 - 样式系统：ASS 样式编辑器、样式管理、实时预览
  4. Phase 4 - 高级功能：格式转换、撤销/重做、快捷键
  5. Phase 5 - 打磨优化：性能优化、测试、文档、国际化
