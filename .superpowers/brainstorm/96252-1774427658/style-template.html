样式模板功能

  • 创建样式：新建空白样式或基于现有样式复制
  • 编辑样式：修改样式属性，实时预览效果
  • 删除样式：删除未使用的样式
  • 应用样式：为字幕条目指定样式
  • 导出样式：将样式导出为 .ass-style.json 文件
  • 导入样式：从文件导入样式到当前项目

样式文件格式

{
  "version": "1.0",
  "name": "我的样式包",
  "author": "用户名",
  "styles": [
    { "name": "Title", "fontName": "Arial", "fontSize": 36, ... },
    { "name": "Dialogue", "fontName": "微软雅黑", "fontSize": 24, ... }
  ],
  "createdAt": 1711344000000
}
