# SubtitleShop

## 中文

SubtitleShop 是一个面向字幕整理与样式管理的桌面工具。  
它的目标很简单：让你更快地把字幕“改对、改齐、改好看”。

### 你可以做什么

- 导入常见字幕文件并进入统一编辑视图
- 一键拆分双行字幕（保持时间轴一致）
- 清理 Dialogue 文本中的中文符号
- 按轨道管理字幕，并批量变更轨道对应样式
- 管理内置样式与预设样式，快速预览视觉效果
- 对样式重命名、新建、复制、删除，并同步关联字幕
- 隐藏低占比轨道、隐藏无引用样式，聚焦有效内容
- 边改边看实时预览，最终导出可用字幕文件

### 适合谁

- 字幕组成员
- 视频后期与压制人员
- 需要批量整理中英双语字幕的人
- 想快速统一字幕风格的人

### 使用流程

1. 导入字幕文件  
2. 在轨道和样式视图中整理内容  
3. 预览确认样式效果  
4. 导出结果文件

## English

SubtitleShop is a subtitle cleanup and style management tool.  
Its purpose is simple: help you fix, align, and polish subtitles faster.

### What You Can Do

- Import common subtitle files into one unified workspace
- Split two-line subtitles in one click (with identical timing)
- Clean Chinese punctuation in Dialogue text blocks
- Manage subtitles by tracks and batch-assign track styles
- Use built-in and preset styles with instant visual preview
- Rename, create, copy, and delete styles while keeping subtitle links updated
- Hide low-share tracks and unused styles to focus on useful content
- Edit with live preview, then export ready-to-use subtitle files

### Who It Is For

- Subtitle teams
- Video post-production users
- People handling bilingual subtitle cleanup at scale
- Anyone who wants consistent subtitle styling quickly

### Typical Workflow

1. Import subtitle files  
2. Organize tracks and styles  
3. Preview and verify appearance  
4. Export the final subtitle file
